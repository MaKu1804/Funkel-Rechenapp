# Rechnen mit Funkel

Mathe-Lern-App für die 1. Klasse: Plus und Minus lernen mit dem Regenbogen-Einhorn Funkel.
Läuft im Browser, auch ohne Internet, und lässt sich als App installieren.

**App öffnen:** https://maku1804.github.io/Funkel-Rechenapp/

## Als App installieren
- **Android (Chrome):** Adresse öffnen → Menü (drei Punkte) → „App installieren“.
- **iPhone/iPad (Safari):** Adresse öffnen → Teilen → „Zum Home-Bildschirm“.

Der Spielstand (Sterne, Funkelsteine, Schrank) bleibt im Browser des Geräts.
Eine neue Fassung holt sich die App beim nächsten Start von selbst.
